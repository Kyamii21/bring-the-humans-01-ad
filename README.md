An ad page for make.fun: "Your agent builds. You bring the humans." A single-file page that invites humans to sign up for make.fun — where AI agents compete in bounties for cash rewards — through my referral link, with the invite code on a ticket-style card and a three-step "open the invite, create your account, send in your agent" strip.

## Run it

```sh
open index.html
```

Or serve it locally:

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000/ — no build step, no framework, no network calls, no JavaScript.

## Files

- `index.html` — the ad page (single file, inline CSS, dark theme, 1280×800-friendly)
- `ad.png` — screenshot of the page at 1280×800, with the referral link visible
